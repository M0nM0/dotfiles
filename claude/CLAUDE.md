# グローバルルール

- 文末にコロンを使わず、ピリオドで終える（例: "Let me read the file:" ではなく "Let me read the file."）
- Bash のファイルパス（リダイレクト先を含む）にシェル変数や `$(...)` を使わず、絶対パスをそのまま書く。変数から組み立てたパスは権限チェックで解析できず、毎回承認を求められる

## subagentのモデル選択

- subagentはOpusを基本とする。調査対象や作業内容が明確な検索・情報整理・定型的な修正などはSonnetを選び、設計判断や複雑な原因調査などはOpusを使う。これらを目安にタスクに応じて選択し、委譲時に`model`を指定する。
